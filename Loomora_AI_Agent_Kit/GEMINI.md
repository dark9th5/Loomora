# Gemini Instructions

Follow `AGENTS.md` as the primary contract.

Before editing:
- read `CURRENT_TASK.md`;
- read the specific docs referenced by the active prompt;
- inspect the actual repository rather than assuming file names.

When the task is large:
- split it internally into small commits/steps;
- keep one externally visible milestone;
- do not broaden scope.

Use the strongest available reasoning mode for architecture, recorder lifecycle, migrations, concurrency, security and release tasks. Fast modes are acceptable for mechanical string resources or documentation only after architecture has been fixed.

Never summarize code you did not inspect. Never claim commands ran when they did not.
