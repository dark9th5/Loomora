# Copywriting and Localization

## Voice

Clear, calm and direct. Avoid exaggerated “magic”, “perfect”, “studio” and “100% accurate” claims.

## Error copy pattern

1. What happened.
2. What is safe.
3. What the user can do.

Example:

> Recording stopped because storage is full. The completed portion has been saved. Free some space, then try again.

## Localization rules

- No string concatenation for sentences.
- Use plurals.
- Format date/time/duration through locale-aware APIs.
- Do not hard-code English in ViewModels.
- Test long Vietnamese strings and large font scale.
