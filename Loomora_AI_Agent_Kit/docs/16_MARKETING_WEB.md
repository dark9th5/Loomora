# Marketing Website and Distribution

## Purpose

The Loomora website explains the product, builds trust, provides Android download/install guidance and supports Pro purchase/contact.

## Pages

- Home.
- Features.
- Pricing.
- Download Android.
- How to install safely.
- Blog.
- Buy/Activate Pro.
- Contact.
- Privacy.
- Terms.
- Data deletion.
- Status/support later.

## Messaging hierarchy

1. Loomora.
2. Smart Voice Recorder & AI Notes.
3. Core local-first promise.
4. Recording reliability.
5. Smart notes and tasks.
6. Free vs Pro.
7. Privacy disclosure.
8. Download/Buy CTA.

## Download

- Prefer Google Play when available.
- Direct APK requires signed release, version, file size and checksum.
- Never host unsigned debug APK.
- Explain Android install warning honestly.
- Keep old vulnerable APKs inaccessible.
- Provide release notes.

## Purchase

Early stage:
- pricing page;
- contact/payment instructions;
- order reference;
- fulfillment status;
- license delivery;
- support channel.

Later:
- payment gateway;
- webhook;
- backend entitlement issuance;
- invoice/receipt;
- automated activation.

## Vercel architecture

Next.js is acceptable. Keep:
- content pages statically generated where possible;
- environment variables for download URL/version/checksum/contact;
- server-only payment/fulfillment secrets;
- abuse protection on forms;
- analytics privacy-conscious;
- SEO metadata, sitemap and structured data.

## Brand consistency

Website and app share:
- Loomora wordmark;
- semantic palette;
- typography principles;
- plan names;
- privacy language;
- screenshots from real builds, not fabricated product states.
