# Code Review Checklist

- [ ] Matches active feature spec.
- [ ] Correct state owner.
- [ ] No I/O in Compose.
- [ ] No fake production data/TODO.
- [ ] Cancellation and lifecycle handled.
- [ ] Typed errors and user-safe messages.
- [ ] Database transaction/migration considered.
- [ ] File operations constrained and recoverable.
- [ ] Security/privacy reviewed.
- [ ] Tests cover rules and regression.
- [ ] No unrelated refactor.
- [ ] Build evidence included.
- [ ] Tracking/docs updated.
