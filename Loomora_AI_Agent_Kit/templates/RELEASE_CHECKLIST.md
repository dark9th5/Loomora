# Release Checklist

## Product
- [ ] Feature scope matches release notes.
- [ ] No dead controls or fake production data.
- [ ] Free offline flow verified.
- [ ] Trial/Pro copy and behavior verified.

## Recording
- [ ] Real record/play smoke test.
- [ ] Pause/resume.
- [ ] Screen off.
- [ ] Interruption/recovery.
- [ ] Storage pressure.
- [ ] Final file integrity.

## Data
- [ ] Migration tests.
- [ ] Trash/permanent deletion.
- [ ] Export.
- [ ] Original preservation.

## UX
- [ ] Light/dark.
- [ ] English/Vietnamese.
- [ ] 200% font.
- [ ] TalkBack.
- [ ] Compact/large screen.
- [ ] Error/offline states.

## Security/privacy
- [ ] No secrets in APK/repo.
- [ ] Exported components reviewed.
- [ ] Logs redacted.
- [ ] Upload disclosure matches behavior.
- [ ] Privacy/terms/data deletion URLs valid.

## Build
- [ ] Clean release build.
- [ ] R8 verified.
- [ ] Signed artifact.
- [ ] Artifact hash.
- [ ] Install/smoke test.
- [ ] Mapping/schema artifacts stored.

## Operations
- [ ] Crash monitoring configured.
- [ ] Support channel ready.
- [ ] Rollback/feature-disable plan.
- [ ] Staged rollout plan.
