# UI Review Checklist

- [ ] Primary action obvious.
- [ ] Layout uses design tokens.
- [ ] No generic sample/dashboard look.
- [ ] Loading/content/empty/error/offline states.
- [ ] All visible controls work.
- [ ] Light and dark designed.
- [ ] 360dp and large width.
- [ ] 200% font scale.
- [ ] 48dp touch targets.
- [ ] TalkBack semantics.
- [ ] State not communicated by color alone.
- [ ] Motion supports understanding.
- [ ] English and Vietnamese copy reviewed.
